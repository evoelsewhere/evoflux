# Provider marks

Monochrome provider glyphs from [LobeHub Icons](https://github.com/lobehub/lobe-icons)
(MIT License, Copyright (c) LobeHub), vendored as EvoFlux does in
`web/src/assets/providers/`.

Each mark is a trademark of its owner and identifies that provider only.
`src/components/provider-icon.tsx` maps provider ids to these files and their
brand colours; providers without a mark fall back to their initials.
