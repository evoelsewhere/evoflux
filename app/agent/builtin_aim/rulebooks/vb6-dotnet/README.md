# Rulebook: vb6-dotnet (draft)

The deliberate proving ground for two of AIM's hardest problems: no usable tree-sitter grammar for VB6 (exercises the structural fallback parser, `extractors/vb6-structural.yaml`), and a typically screen-heavy estate (exercises the §3.13A UI/UX rules end to end — see `ui-patterns/vb6-to-dotnet-ui-patterns.md` and the `target-base/checklist.md` UI-kit gate). Per `documents/research/aim-framework.md` §4.1.

**Status: content-only (AIM-0).** Not yet installed anywhere; the structural parser it targets (`parsers/structural.py`) is AIM-2/3 work, and the `aim_rulebook_service` that would install this pack is AIM-1 work.
