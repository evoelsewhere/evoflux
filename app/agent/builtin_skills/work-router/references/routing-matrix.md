# Work routing matrix

Use the requested outcome—not the document noun—to choose a specialist.

| Primary question | Specialist | Boundary |
| --- | --- | --- |
| What does the supplied data show? | `work-data-analysis` | External fact-finding belongs to research. |
| Which option should we choose? | `work-decision` | A comparison without a recommendation may be research. |
| How will we deliver this outcome? | `work-planning` | A personal checklist with no dependencies may need no skill. |
| What is true according to current sources? | `work-research` | Existing supplied evidence may only need synthesis. |
| How should we communicate this conclusion? | `work-writing` | Drafting does not authorize inventing missing facts. |

## Useful sequences

- Research → decision: collect decision-changing evidence, then recommend.
- Data analysis → decision: establish metrics and uncertainty before weighing
  options.
- Decision → planning: freeze the chosen direction before sequencing work.
- Research or analysis → writing: treat the evidence artifact as the source of
  truth; writing changes expression, not facts.

When the user asks for all stages at once, activate specialists sequentially
and carry forward a compact artifact: evidence ledger, decision record, or
execution plan. Avoid loading every specialist body simultaneously.
