# Decision rubric

Use this rubric for consequential or contested choices.

## Evidence classes

- Constraint: eliminates an option if verified.
- Outcome evidence: predicts value or user impact.
- Execution evidence: predicts time, feasibility, or operating burden.
- Risk evidence: predicts downside likelihood, blast radius, or recovery.
- Preference: matters to stakeholders but is not an external fact.
- Assumption: currently unverified and should carry an owner or test.

## Scoring discipline

Use weights only when stakeholders can defend their relative importance.
Normalize score direction, show evidence beside every score, and run a
sensitivity check: vary uncertain weights and scores enough to see whether the
winner changes. If small changes reverse the result, the matrix has exposed an
unstable decision—not selected a winner.

## Reversibility

Classify the commitment:

- Reversible: cheap exit; optimize for learning speed.
- Reversible with switching cost: define an exit threshold and preserve data.
- Hard to reverse: require stronger evidence, staged proof, and explicit owner.
- Irreversible: require authority, failure containment, and acceptance of loss.

State the decision horizon. An option that wins for six months may lose over
three years; do not blend horizons into one score.
