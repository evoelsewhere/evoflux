# Orchestration patterns

Read this file before delegating doubt-driven investigations.

## Ownership

The main session owns the task, evidence ledger, synthesis, and final decision.
Personas investigate bounded questions and return evidence; they do not create
or manage other personas.

## Dispatch

- Give each persona one falsifiable question and a clear output contract.
- Separate independent hypotheses so investigators do not anchor one another.
- Provide source artifacts, not the expected conclusion.
- Keep mutations out of investigation tasks unless explicitly required.

## Synthesis

- Compare claims against primary evidence.
- Record contradictions instead of averaging them away.
- Resolve gaps with a targeted follow-up, not another broad investigation.
- Stop when new evidence no longer changes the decision materially.
