# EvoFlux Brand Assets

App-imported brand assets used by React components.

## Files

- `evoflux-app-icon.png` - rounded-diamond flow-mark logo icon for app chrome / avatar tile
- `logo.svg` - canonical vector source (project root)

Documentation exports live in `docs/images/`. The browser-public copy in
`web/public/brand-assets/` is only for direct URL needs such as the favicon.
