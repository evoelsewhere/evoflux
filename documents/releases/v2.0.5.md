# EvoFlux v2.0.5

EvoFlux 2.0.5 is a maintenance release focused on Windows reliability, Coding
project workflows, and clearer agent interaction feedback.

## Highlights

- Fixed Windows plugin uninstall/update operations that could fail with access
  denied errors.
- Normalized Windows extended-length workspace paths across the desktop and
  web clients.
- Improved multi-repository Coding projects with multi-folder selection and
  repository targeting for new ASDD changes.
- Prevented portal popups from being treated as title-bar drag regions and
  restored the lead agent transcript in Agent view mode.
- Refined turn loading feedback and removed the team activity log wiring.

## Upgrade notes

- Application, Python, web, Rust, Tauri and lockfile metadata are synchronized
  at `2.0.5`.
- No database migration is introduced by the release version bump itself;
  production startup continues to validate and apply migrations normally.
- Tagged builds produce platform packages and updater metadata through the
  desktop package workflow after required signing secrets are available.

## Verification scope

The release follows the checklist in
[`documents/development/release-and-packaging.md`](../development/release-and-packaging.md),
with focused frontend, backend, Rust and package-workflow checks for the
changes included since v2.0.4.
