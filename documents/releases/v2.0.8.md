# EvoFlux v2.0.8

EvoFlux 2.0.8 is a focused WebBridge and document-workbench release that
improves browser debugging, live spreadsheet authoring, and file previews.

## Highlights

- Added WebBridge debugging for console messages, uncaught errors, network
  requests, response bodies, storage, cookies, uploads, performance, and
  source-mapped component inspection.
- Added hot-module-reload checks and surfaced browser build/runtime failures in
  the Problems panel.
- Added live workbook authoring with cell selection, editing, and preview
  support alongside the existing live deck workflow.
- Improved document previews, browser tooling, tool-schema size, and WebBridge
  guidance for Coding sessions.
- Removed obsolete ASDD autopilot and the unused ONNX/MarkItDown stack.

## Upgrade notes

- Application, Python, web, Rust, Tauri and lockfile metadata are synchronized
  at `2.0.8`.
- No database migration is introduced by the release version bump itself;
  production startup continues to validate and apply migrations normally.
- Tagged builds produce platform packages and updater metadata through the
  desktop package workflow after required signing secrets are available.

## Verification scope

The release follows the checklist in
[`documents/development/release-and-packaging.md`](../development/release-and-packaging.md),
with focused WebBridge, document-preview, workbook, frontend, backend, Rust,
and desktop packaging checks for the changes included since v2.0.7.
