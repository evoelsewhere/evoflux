# EvoFlux v2.0.9

EvoFlux 2.0.9 extends Computer App Control to macOS, bringing the same
permission-aware desktop-app workflow to both supported desktop platforms.

## Highlights

- Added macOS Computer App Control for attaching to, previewing, inspecting,
  and operating one application window through the Accessibility API and
  window-server capture.
- Added macOS permissions guidance in Settings for Accessibility and Screen &
  System Audio Recording, including direct links to the relevant System
  Settings panes and restart support.
- Added cross-platform app-control APIs, settings routes, permission policy,
  preview UI, virtual cursor feedback, and installed-app discovery.
- Added Windows and macOS computer-app integration tests and desktop permission
  capabilities.

## Upgrade notes

- Application, Python, web, Rust, Tauri and lockfile metadata are synchronized
  at `2.0.9`.
- Computer App Control remains disabled by default and requires explicit user
  permission and app allowlisting.
- Tagged builds produce platform packages and updater metadata through the
  desktop package workflow after required signing secrets are available.

## Verification scope

The release follows the checklist in
[`documents/development/release-and-packaging.md`](../development/release-and-packaging.md),
with focused Computer App Control, permission, frontend, backend, Rust, and
desktop packaging checks for the changes included since v2.0.8.
