# EvoFlux v2.0.4

EvoFlux 2.0.4 is a feature and architecture release focused on ASDD, native
MCP 2.2 support, browser agent previews, and runtime consolidation.

## Highlights

- **ASDD transition:** replace the legacy EASD naming and runtime surfaces with
  repository-native Agent Specification-Driven Development changes.
- **Suggested tasks:** park out-of-scope findings as one-click sessions for
  later execution.
- **Native MCP 2.2 runtime:** use the native Streamable HTTP/httpx2 transport,
  typed session runner boundaries, structured MCP results, and compatibility
  support for existing integrations.
- **Browser agent previews:** `browser_use` opens the existing PIP surface
  instead of taking over the Browser workbench, with multiple stacked
  session-specific previews.
- **Skill consolidation:** remove redundant bundled skills and fold research
  and paper-writing workflows into `super-research`.

## Upgrade notes

- Application, Python, web, Rust, Tauri and lockfile metadata are synchronized
  at `2.0.4`.
- No database migration is introduced by the release version bump itself;
  production startup continues to validate and apply migrations normally.
- Tagged builds produce platform packages and updater metadata through the
  desktop package workflow after required signing secrets are available.

## Verification scope

The release follows the checklist in
[`documents/development/release-and-packaging.md`](../development/release-and-packaging.md),
including version synchronization, backend/frontend/Rust checks, ASDD and MCP
focused tests, browser/PIP regression tests, sidecar health validation and
desktop package workflow verification.
