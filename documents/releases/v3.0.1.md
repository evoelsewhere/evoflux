# EvoFlux v3.0.1

EvoFlux 3.0.1 consolidates the desktop-control update shipped after v3.0.0:
better macOS parked-app control, safer desktop updates, startup/tray controls,
and a clearer Remote Control setup experience.

## Highlights

- Computer App Control on macOS can drive parked Chrome and Electron windows
  without leaving menus or overlays on screen, then restores the parked window
  after actions and crash recovery.
- Desktop settings now include Run on startup, system-tray visibility and
  Keep computer awake controls, with platform-aware permissions and updater
  behavior.
- Remote Control setup now explains its policy, setup steps and live status;
  the existing embedded Tailscale transport and one-device lock remain intact.
- WebBridge browser selection and per-chat tab ownership are clearer, with
  improved browser debugging and reduced accidental cross-tab actions.
- Windows title-bar behavior, macOS traffic-light alignment, Git text decoding
  and update installation flow were hardened.

## Upgrade notes

- The release is based on the latest `main` after the v3.0.0 release line.
- Computer App Control remains opt-in and can require Accessibility/Screen
  Recording permissions on macOS.
- Existing Remote Control and external Tailscale CLI fallback configuration is
  preserved.
