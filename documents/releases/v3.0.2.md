# EvoFlux v3.0.2

EvoFlux 3.0.2 focuses on coding reliability, desktop control and a tighter
everyday chat experience after the 3.0.1 release.

## Highlights

- Coding is now project-first across sessions, worktrees, scheduler tasks,
  file trees, problems, reviews and repository-aware commands.
- Computer App Control on macOS can operate parked Chrome/Electron windows
  without leaving menus or overlays on screen, with improved capture and
  crash recovery.
- Remote Control setup has clearer policy guidance, live status and the
  embedded Tailscale flow remains available from the desktop package.
- Desktop settings add startup, tray visibility and keep-awake controls;
  updater downloads are reused and installation waits for restart or quit.
- WebBridge now keeps each chat in its own browser tab and installs through
  the Chrome Web Store; chat composer, sidebar and coding surfaces received
  responsive and rendering optimizations.

## Upgrade notes

- Existing settings and Remote Control state are preserved.
- Computer App Control remains opt-in and may require Accessibility and Screen
  Recording permissions on macOS.
- Coding data migration files sessions into projects where ownership is
  unambiguous; standalone repositories remain available for explicit project
  setup.
