# EvoFlux v2.0.7

EvoFlux 2.0.7 is a focused Office and document-preview release that improves
live deck authoring, generated-file discovery, and turn-level visual feedback.

## Highlights

- Added turn file cards with thumbnails and direct navigation into the Files
  workbench for generated artifacts.
- Let agents choose which generated images appear as cards and avoid showing
  transient scratch renders.
- Improved live PowerPoint previews with per-slide placeholders and stable,
  compact page controls while a deck is being built.
- Let deck QA repair a finished deck without restarting the original live
  preview or reprocessing unrelated slides.
- Scoped slide edits to their target slides and refined the PPTX/Office Skills
  supporting live deck generation and annotation workflows.

## Upgrade notes

- Application, Python, web, Rust, Tauri and lockfile metadata are synchronized
  at `2.0.7`.
- No database migration is introduced by the release version bump itself;
  production startup continues to validate and apply migrations normally.
- Tagged builds produce platform packages and updater metadata through the
  desktop package workflow after required signing secrets are available.

## Verification scope

The release follows the checklist in
[`documents/development/release-and-packaging.md`](../development/release-and-packaging.md),
with focused Office-preview, live-deck, turn-file-card, frontend, backend,
Rust, and desktop packaging checks for the changes included since v2.0.6.
