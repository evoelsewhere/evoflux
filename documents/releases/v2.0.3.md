# EvoFlux v2.0.3

EvoFlux 2.0.3 is a maintenance release focused on updater feedback, coding
skill routing and EASD workspace correctness.

## Highlights

- **Updater recovery:** the desktop updater now shows what it is doing,
  reports failures as actionable state and leaves the application window
  usable after a failed update.
- **Coding skill routing:** thirteen overlapping coding skills are consolidated
  into four hubs — `coding-change`, `coding-investigate`, `coding-operate` and
  `coding-verify` — with refreshed references, evals and loader behavior.
- **Consistent observation budgets:** observation limits are owned by the
  routing hubs and shared consistently by their workflows.
- **EASD workspace correctness:** an EASD run now keeps the workspace selected
  for the run instead of inheriting an unrelated workspace from its linked
  chat request.

## Upgrade notes

- Application, Python, web, Rust, Tauri and lockfile metadata are synchronized
  at `2.0.3`.
- No database migration is introduced; existing databases continue through the
  normal Alembic compatibility path.
- Tagged builds produce platform packages and updater metadata through the
  desktop package workflow after required signing secrets are available.

## Verification scope

The release follows the checklist in
[`documents/development/release-and-packaging.md`](../development/release-and-packaging.md),
including version synchronization, frontend/Rust/backend checks, skill-loader
and updater tests, sidecar handshake/auth/health validation and desktop package
workflow verification.
