# EvoFlux v2.0.1

EvoFlux 2.0.1 is a focused maintenance release for browser workflows, the
Problems panel, and EASD portability.

## Highlights

- **Browser workflows:** detached pages, drag-to-resize previews, device and
  layout controls, per-site zoom, download history, explicit loading/error
  states, and shortcuts that return control to the panel.
- **Actionable Problems:** accurate filters, counts, pluralization, and
  severity; durable user decisions; reversible dismissal; draft-preserving
  “Send to agent”; and automatic removal of fixed problems.
- **EASD portability:** import support and cleanup of stale documentation
  artifacts keep repository-backed specifications portable and current.
- **Workbench reliability:** scoped desktop webview capability and remembered
  maximize posture across restarts.

## Upgrade notes

- Application, Python, web, Rust, Tauri, and lockfile metadata are synchronized
  at `2.0.1`.
- This is a backward-compatible maintenance update on the 2.0.0 baseline.
- Existing databases continue through the normal Alembic migration path.
