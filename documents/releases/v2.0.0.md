# EvoFlux v2.0.0

EvoFlux 2.0.0 is the second major release of the local-first desktop workspace
for Work and Coding agent teams.

This release advances the stable baseline with a redesigned multi-session
workbench, a shared provider capability layer, deeper browser automation,
measurable context and cost controls, stronger Evo Agent Specs, and the client
foundation for organization-managed resources through Evo Conductor.

## Highlights

- **Evo Conductor foundation:** authenticated realtime resource events,
  resilient reconciliation, registry and inventory integration, credential
  recovery, delivery notices, and privacy-safe telemetry fields.
- **Multi-session workbench:** terminals, browsers, files, and docked tools are
  retained by session; background completion remains visible; returning to a
  recent conversation is faster and steadier.
- **Provider intelligence:** one declarative provider/model layer, live catalog
  refresh, accurate capability and thinking-level validation, subscription
  pricing, Xiaomi MiMo support, and cache-aware Codex continuity.
- **Browser and preview:** authenticated bridge routes, stable element
  references, selected-browser routing, safer ownership and reconnect behavior,
  workspace dev-server launch, and improved document and HTML previews.
- **Usage and observability:** tunable context windows, per-turn token and cost
  reporting, cache-read/write visibility, model-stacked charts, and service-tier
  telemetry.
- **Evo Agent Specs:** portable session rebinding, run execution controls,
  code-context contracts, measured verification commands, and more reliable
  recovery and convergence.
- **Reliability and security:** DNS-rebinding and private-network protection,
  migration repair, background process polling, CJK input fixes, widget
  recovery, and stronger browser lifecycle handling.

## Distribution

The tagged release workflow builds and validates:

- macOS DMG for Apple Silicon;
- macOS DMG for Intel;
- Windows x64 NSIS installer;
- Linux x64 DEB package;
- signed updater metadata and SHA-256 checksums where applicable.

The Python wheel remains the API-sidecar distribution. Native desktop packages
contain the full EvoFlux product.

## Upgrade notes

- Application, Python, web, Rust, Tauri, and lockfile metadata are synchronized
  at `2.0.0`.
- Existing databases use the normal Alembic migration path. Back up important
  production workspaces before upgrading.
- Validate provider credentials, browser selection, and organization-managed
  resource delivery after upgrade because these subsystems changed materially.
- Linux direct browser input continues to require X11/XWayland.
