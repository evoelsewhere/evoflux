# EvoFlux v2.0.6

EvoFlux 2.0.6 is a feature and architecture release focused on the new Agent
Skills runtime, a simpler Coding workbench, richer Office/document handling,
and more reliable agent execution.

## Highlights

- Migrated Agent Skills to the Anthropic filesystem architecture, including
  project/user discovery, `$skill-name` invocation, direct `SKILL.md` loading,
  and bundled script execution.
- Removed the legacy Workflow, ASDD, and code-graph product surfaces, along
  with their obsolete APIs, UI panels, skills, and persistence paths.
- Added StepFun as a first-class model provider and improved streamed tool-call
  compatibility, context compaction, token accounting, and reconnect behavior.
- Expanded DOCX, PPTX, XLSX, and PDF preview capabilities with an optional
  LibreOffice runtime, live slide-by-slide deck previews, document versioning,
  and Office annotation editing.
- Simplified the Coding workbench by consolidating source control/review and
  terminal/process surfaces while improving global search and workspace state.

## Upgrade notes

- Application, Python, web, Rust, Tauri and lockfile metadata are synchronized
  at `2.0.6`.
- Migration `00000068` removes the obsolete Workflow persistence tables.
- Existing `.evoflux/workflows/*.yaml` files and legacy ASDD/code-graph surfaces
  are no longer read by the application.
- Tagged builds produce platform packages and updater metadata through the
  desktop package workflow after required signing secrets are available.

## Verification scope

The release follows the checklist in
[`documents/development/release-and-packaging.md`](../development/release-and-packaging.md),
