# EvoFlux 3.0.8

Released 2026-10-15.

This release improves recovery and completion reporting for long-running agent
tasks:

- Desktop app control deadlines now cover queued actions and websocket sends.
- Shell polling returns after a bounded stdout drain when a descendant keeps a
  pipe open, and marks the output as potentially incomplete.
- Agents recover once when a model emits tool-call markup as plain text; repeated
  malformed output now fails clearly instead of appearing complete.
- Worktree finalization accepts a redundant model-supplied `task_id` while
  retaining repository scoping.
- Provider response streams preserve incomplete and token-limit finish reasons.
  Text-item completion no longer ends the whole response prematurely.
