# EvoFlux v2.0.2

EvoFlux 2.0.2 is a maintenance release focused on deeper WebBridge browser
inspection and more reliable browser interaction workflows.

## Highlights

- **Deep WebBridge inspection:** `extract_elements` can search within a selected
  element and traverse shadow roots and frames, while returning bounded,
  provenance-preserving results.
- **Nested scrolling:** `scroll_to_bottom` accepts a selector or element ref so
  the agent can scroll the pane that actually owns the records.
- **Reliable browser actions:** stable element handles, changed-only snapshots,
  batched action chains and explicit broken-chain recovery reduce repeated page
  reads and prevent stale actions from being applied silently.
- **Browser workflow follow-up:** Preview/PiP handoff, resize/placement,
  dialog/permission routing and workbench ownership fixes are included from the
  post-2.0.1 maintenance cycle.

## Upgrade notes

- Application, Python, web, Rust, Tauri and lockfile metadata are synchronized
  at `2.0.2`.
- No database migration is introduced; existing databases continue through the
  normal Alembic compatibility path.
- Tagged builds produce platform packages and updater metadata through the
  desktop package workflow after required signing secrets are available.

## Verification scope

The release change must pass the release checklist in
[`documents/development/release-and-packaging.md`](../development/release-and-packaging.md),
including version synchronization, backend/frontend/Rust checks, WebBridge
focused tests, migration compatibility, sidecar handshake/health and package
workflow validation.
