# EvoFlux v3.0.0

EvoFlux 3.0 is the desktop control release: Remote Control is built into the
desktop package, Computer App Control is available across macOS and Windows,
and the mobile/streaming surfaces have been tightened for daily use.

## Highlights

- Embedded Tailscale Remote Control through a bundled `tsnet` helper. Users
  connect once from Settings → Phone access; no Homebrew, CLI or system daemon
  is required on packaged desktops.
- Private tailnet URLs and QR onboarding, with WhoIs identity verification,
  HTTP/WebSocket authorization and a one-device remote session lock.
- Computer App Control with background window attachment, screenshots,
  accessibility/UI inspection, input actions, policy controls and platform
  permission guidance.
- Mobile-first interaction polish: safe-area-aware shell chrome, larger touch
  targets, responsive drawers, a two-row chat composer and cleaner settings
  navigation at phone widths.
- Desktop package support for the embedded tailnet helper on macOS Intel,
  macOS Apple Silicon, Windows x64 and Linux x64.

## Upgrade notes

- Packaged users open Settings → Phone access and click Connect once. The
  phone must have Tailscale installed and be signed in to the same tailnet.
- Remote Control remains available to source deployments through the external
  Tailscale CLI fallback.
- Computer App Control is opt-in. macOS users may need Accessibility and
  Screen & System Audio Recording permissions; Windows users need the normal
  desktop app-control policy approval.
