# EvoFlux Brand Assets

Geometric hexagon logo assets.

## Files

- `evoflux-app-icon.png` - logo icon for app chrome / avatar tile
- `logo.svg` - canonical vector source (project root)

App-imported copies live in `../../../web/src/assets/brand/`. The browser-public copy in `../../../web/public/brand-assets/` is only for direct URL needs such as the favicon.

## Palette

- Cyan: `#00F0FF`
- Blue: `#0078FF`
- Indigo: `#6366F1`
- Purple: `#A855F7`
- Deep purple: `#3B0764`
