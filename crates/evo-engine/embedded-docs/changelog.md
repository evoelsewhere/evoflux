# Changelog

All notable changes to the `evo-*` crate family are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and the project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

The evo-* crates share one workspace version and are released together
in dependency order. `git tag vX.Y.Z` marks the commit that a release was cut
from; the matching [GitHub Release](../../releases) carries the same notes.

## [0.1.0] - 2026-11-05

### Added

- First release of the `evo-*` crate family: `evo-ai`, `evo-agent`,
  `evo-tools`, `evo-harness`, `evo-durable`, `evo-runtime`, `evo-extensions`,
  `evo-plugin-sdk`, `evo-telemetry`, `evo-tui` and the `evo` CLI (`evo-cli`).
